# Sketch2CAD

כלי מקומי (Windows) שהופך סקיצות, צילומים, פרטים טיפוסיים וקבצי PDF לשרטוטי AutoCAD (DXF, DWG, PDF). הכלי כולל ניהול פרויקטים, קוד פנימי למסמכים, תבניות כותרת, קטלוג פריטים עם מקורות, בדיקות הנדסיות, כתב כמויות, תיק הגשה וחיפוש, בעברית ובאנגלית.

- **אפיון:** [docs/SPEC.md](docs/SPEC.md)
- **פורמטים פנימיים ו-API:** [docs/FORMATS.md](docs/FORMATS.md)
- **דוגמאות:** `examples/`. מפרטי `spec.json` של חיבור הגמל ושל הצעת תעלות מבנה P.
- **אב-טיפוס:** `prototypes/`. הסקריפטים המקוריים, והקבצים שהם הפיקו ב-`prototypes/outputs/`.

## התקנה והפעלה (Windows)
1. מורידים את התוכנה: **[Sketch2CAD-main.zip](https://github.com/rotem-ya/Sketch2CAD/archive/refs/heads/main.zip)**, ומחלצים לתיקייה קבועה, למשל `C:\Sketch2CAD`. לא לתיקייה תחת `Program Files` (Windows חוסם שם כתיבה, והתוכנה צריכה לשמור הגדרות ועדכונים ליד עצמה).
2. לוחצים פעמיים על `install.bat`. הקובץ מאתר Python נתמך (3.11 עד 3.14; ל-3.15 ומעלה עדיין אין חבילות מוכנות) ומתקין Python 3.12 אם אין (דרך winget), מתקין את כל הספריות ויוצר קיצור דרך "Sketch2CAD" בשולחן העבודה. לוקח כמה דקות, ורק בפעם הראשונה. בסוף הוא שואל איפה לשמור את **הנתונים** (הגדרות, אינדקס חיפוש, קטלוג ותבניות אישיות): Enter לברירת המחדל (`%APPDATA%\Sketch2CAD`), או נתיב בכונן אחר, למשל `E:\Sketch2CAD\Data`. אפשר לשנות אחר כך במסך ההגדרות.
3. מפעילים מקיצור הדרך "Sketch2CAD" בשולחן העבודה (או `run.bat`). התוכנה נפתחת בחלון משלה, בלי חלון שחור, וסגירת החלון סוגרת אותה (או הכפתור ⏻ בתחתית התפריט). אפשר גם לפתוח אותה בדפדפן בכתובת http://localhost:8517. לבירור תקלות: `run-debug.bat` מריץ עם חלון שמציג את כל ההודעות, והן נשמרות תמיד גם ב-`logs\app.log` בתיקיית הנתונים. במחשב שהותקן לפני גרסה זו קיצור הדרך הישן ממשיך לעבוד (עם הבהוב קצר של חלון שחור); הרצת `install.bat` שוב מחליפה אותו.
4. **DWG:** אם מותקן AutoCAD מלא, התוכנה משתמשת בו אוטומטית להמרה ל-DWG (דרך accoreconsole) ואין צורך בשום דבר נוסף. בלי AutoCAD (או עם AutoCAD LT) מתקינים את [ODA File Converter](https://www.opendesign.com/guestfiles/oda_file_converter), שהוא חינמי לשימוש פנימי. בלשונית "תוצרים" יש כפתור "פתח באוטוקד".
5. לקריאת סקיצות עם AI מזינים מפתח Claude API במסך ההגדרות.

**איפה הקבצים:** התוכנה עצמה בתיקיית ההתקנה (למשל `C:\Sketch2CAD`). הפרויקטים בתיקייה שבוחרים לכל פרויקט (ברירת המחדל נקבעת במסך ההגדרות, למשל `E:\Sketch2CAD\Projects`). הנתונים המשותפים (הגדרות, אינדקס חיפוש, קטלוג ותבניות אישיות) בתיקיית הנתונים, שנבחרת ב-`install.bat` או במסך ההגדרות ונשמרת בקובץ `data_home.txt` ליד התוכנה. שינוי תיקיית הנתונים מעתיק אליה את הנתונים הקיימים, ותיקייה שכבר יש בה נתונים (למשל ממחשב קודם) נשארת כמו שהיא. עדכון גרסה לא נוגע בשום דבר מזה.

**עדכון גרסה:** בתחתית התפריט הצדדי מוצגת הגרסה המותקנת. התוכנה בודקת לבד אם יש גרסה חדשה (או בכפתור "🔄 בדוק עדכונים"). כשיש, לוחצים "⬇️ עדכן עכשיו": התוכנה נסגרת, מורידה את הגרסה החדשה, מתקינה ספריות חדשות אם צריך, ונפתחת מחדש. אם התוכנה לא נפתחת בכלל, סוגרים אותה ומפעילים `update.bat`. העדכון לא נוגע בפרויקטים ובהגדרות.

## מה יש בתוכנה
| מסך | מה עושים בו |
|---|---|
| פרויקטים | יצירת פרויקט (כולל **מילוי הפרטים מתוך מסמך** עם AI, ובחירת תיקייה בכפתור 📂), ותיקייה קבועה לכל פרויקט שאפשר להעביר. מבנה התיקייה: `00_Sources`, `10_Drawings`, `20_Imports`, `90_Archive` |
| פרויקט | רשימת מסמכים עם סינון וחיפוש, מסמך חדש עם קוד אוטומטי, **סט הדפסה** (PDF אחד עם רשימת גיליונות וסימניות), הגדרות |
| מסמך | פרטים, מקורות (הטקסט מכל קובץ נכנס לחיפוש, גם ממיילים), **שרטוט** (מפרט מפרט טיפוסי, מסקיצה עם AI או מ-JSON, ובחירת תבנית כותרת ושינוי הכותרת; **סימון ותיקון לפי בקשה**: סימון על השרטוט בעט חופשי ובקווים ישרים, כתיבת מה לשנות, והשרטוט מתוקן ומופק מחדש עם אפשרות לבטל), **בדיקות**, **כתב כמויות** (Excel), תוצרים, **תיק הגשה**, **השוואת מהדורות**, מהדורות |
| ייבוא והמרה | פתיחה ותצוגה של DWG, DXF, PDF, תמונות ו-IFC. המרות: PDF ל-DXF או DWG בקנה מידה, DXF ל-DWG ובחזרה, IFC לתוכנית DXF. שמירה כמסמך בפרויקט |
| מייל | מעלים מייל של בודק (msg. מ-Outlook או eml.). התוכנה קוראת את ההערות ואת הקבצים המצורפים, מזהה לבד לאיזה פרויקט ומסמך הם שייכים (קוד המסמך, קבצים של המסמך, קוד הפרויקט ומילים משותפות; אפשר לשנות), שומרת את המייל והקבצים במקורות המסמך, ומתקנת את השרטוט לפי ההערות כשהקבצים המצורפים (העתק מסומן, תכנון מקורי, דפי קטלוג) נשלחים ל-AI יחד עם הבקשה |
| תבניות כותרת | צפייה בתבניות ועריכתן, ושמירת עותק כתבנית אישית |
| קטלוג | אביזרים עם מידות ומקור לכל מידה (הגשה וקובץ). מידות בלי מקור מסומנות. שמירה לקטלוג הפרויקט או לקטלוג האישי |
| חיפוש | חיפוש בכל הפרויקטים לפי קוד, כותרת, תיאור, תגיות ותוכן הקבצים. חיפוש "גמל" מוצא גם "לגמל" |

**שגיאות AI:** כשקריאה ל-Claude נכשלת, התוכנה מסבירה מה לעשות: נגמר הקרדיט בחשבון Anthropic (טוענים ב-Plans & Billing), מפתח שגוי, אין חיבור, עומס זמני. ההודעה המקורית מופיעה מתחת.

**Revit:** אין קורא RVT חינמי ומקומי. ב-Revit מבצעים File > Export > IFC ומייבאים את ה-IFC.

## בדיקות
```bash
pip install -r requirements.txt
python -m pytest -q
```
את בדיקת ההמרה ל-DWG מריצים כשמשתנה הסביבה `ODA_CONVERTER` מצביע על הממיר. בלי הממיר הבדיקה מדולגת.
