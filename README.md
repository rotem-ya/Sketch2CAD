# Sketch2CAD

כלי מקומי (Windows) שהופך סקיצות, צילומים, פרטים טיפוסיים וקבצי PDF לשרטוטי AutoCAD (DXF, DWG, PDF). הכלי כולל ניהול פרויקטים, קוד פנימי למסמכים, תבניות כותרת, קטלוג פריטים עם מקורות, בדיקות הנדסיות, כתב כמויות, תיק הגשה וחיפוש, בעברית ובאנגלית.

- **אפיון:** [docs/SPEC.md](docs/SPEC.md)
- **פורמטים פנימיים ו-API:** [docs/FORMATS.md](docs/FORMATS.md)
- **דוגמאות:** `examples/`. מפרטי `spec.json` של חיבור הגמל ושל הצעת תעלות מבנה P.
- **אב-טיפוס:** `prototypes/`. הסקריפטים המקוריים, והקבצים שהם הפיקו ב-`prototypes/outputs/`.

## התקנה והפעלה (Windows)
1. מורידים את התוכנה: **[Sketch2CAD-main.zip](https://github.com/rotem-ya/Sketch2CAD/archive/refs/heads/main.zip)**, ומחלצים לתיקייה קבועה, למשל `C:\Sketch2CAD`.
2. לוחצים פעמיים על `install.bat`. הקובץ מתקין Python אם הוא חסר (דרך winget), מתקין את כל הספריות ויוצר קיצור דרך "Sketch2CAD" בשולחן העבודה. לוקח כמה דקות, ורק בפעם הראשונה.
3. מפעילים מקיצור הדרך (או `run.bat`). התוכנה נפתחת בדפדפן בכתובת http://localhost:8517.
4. **DWG:** אם מותקן AutoCAD מלא, התוכנה משתמשת בו אוטומטית להמרה ל-DWG (דרך accoreconsole) ואין צורך בשום דבר נוסף. בלי AutoCAD (או עם AutoCAD LT) מתקינים את [ODA File Converter](https://www.opendesign.com/guestfiles/oda_file_converter), שהוא חינמי לשימוש פנימי. בלשונית "תוצרים" יש כפתור "פתח באוטוקד".
5. לקריאת סקיצות עם AI מזינים מפתח Claude API במסך ההגדרות.

**עדכון גרסה:** בתחתית התפריט הצדדי מוצגת הגרסה המותקנת. התוכנה בודקת לבד אם יש גרסה חדשה (או בכפתור "🔄 בדוק עדכונים"). כשיש, לוחצים "⬇️ עדכן עכשיו": התוכנה נסגרת, מורידה את הגרסה החדשה, מתקינה ספריות חדשות אם צריך, ונפתחת מחדש. אם התוכנה לא נפתחת בכלל, סוגרים אותה ומפעילים `update.bat`. העדכון לא נוגע בפרויקטים ובהגדרות.

## מה יש בתוכנה
| מסך | מה עושים בו |
|---|---|
| פרויקטים | יצירת פרויקט (כולל **מילוי הפרטים מתוך מסמך** עם AI, ובחירת תיקייה בכפתור 📂), ותיקייה קבועה לכל פרויקט שאפשר להעביר. מבנה התיקייה: `00_Sources`, `10_Drawings`, `20_Imports`, `90_Archive` |
| פרויקט | רשימת מסמכים עם סינון וחיפוש, מסמך חדש עם קוד אוטומטי, **סט הדפסה** (PDF אחד עם רשימת גיליונות וסימניות), הגדרות |
| מסמך | פרטים, מקורות (הטקסט מכל קובץ נכנס לחיפוש), **שרטוט** (מפרט מפרט טיפוסי, מסקיצה עם AI או מ-JSON, ובחירת תבנית כותרת ושינוי הכותרת), **בדיקות**, **כתב כמויות** (Excel), תוצרים, **תיק הגשה**, **השוואת מהדורות**, מהדורות |
| ייבוא והמרה | פתיחה ותצוגה של DWG, DXF, PDF, תמונות ו-IFC. המרות: PDF ל-DXF או DWG בקנה מידה, DXF ל-DWG ובחזרה, IFC לתוכנית DXF. שמירה כמסמך בפרויקט |
| תבניות כותרת | צפייה בתבניות ועריכתן, ושמירת עותק כתבנית אישית |
| קטלוג | אביזרים עם מידות ומקור לכל מידה (הגשה וקובץ). מידות בלי מקור מסומנות. שמירה לקטלוג הפרויקט או לקטלוג האישי |
| חיפוש | חיפוש בכל הפרויקטים לפי קוד, כותרת, תיאור, תגיות ותוכן הקבצים. חיפוש "גמל" מוצא גם "לגמל" |

**Revit:** אין קורא RVT חינמי ומקומי. ב-Revit מבצעים File > Export > IFC ומייבאים את ה-IFC.

## בדיקות
```bash
pip install -r requirements.txt
python -m pytest -q
```
את בדיקת ההמרה ל-DWG מריצים כשמשתנה הסביבה `ODA_CONVERTER` מצביע על הממיר. בלי הממיר הבדיקה מדולגת.
